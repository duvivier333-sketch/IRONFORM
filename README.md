# IRONFORM

Prototype web responsive inspiré de la maquette IRONFORM.

## Stack
- Next.js
- React
- TypeScript
- Lucide icons

## Lancer en local
```bash
npm install
npm run dev
```

## Fonctionnalités de cette V1
- Dashboard
- Démarrage de séance
- Saisie poids / répétitions
- Écran de repos
- Historique des séances
- Progression
- Programme / phases
- Milestones
